## 范围与隐私

`render_synthetic_result_scatter` 将调用方提供的一组结果点显示为内存中的独立 SVG 资产。不拟合分布、不连线或插值数据点、不绘制概率图、不计算区间、不预测、不重新计算结果。未接入 dispatcher 或 HTML 报告渲染器，现有计算器和报告行为不变。

`data_origin: "synthetic"` 仅为调用方声明。输出明确设置 `origin_verified=False`，不会认证数据来源、正确性、单位或含义。此演示不得输入客户、公司、个人或其他真实记录。返回的资产元数据和 SVG 均包含标签及归一化后的点值。

## 输入契约

请求必须是普通 `dict`，且恰好包含 `data_origin`、`title`、`estimand`、`x_axis`、`y_axis`、`points`。不接受未知字段或缺失字段。来源标记必须是精确字符串 `synthetic`。

- `title`、`estimand`：普通字符串，去除首尾空白后非空，最多分别为 120、100 个字符。
- 每个坐标轴：普通 `dict`，恰好包含 `label` 和 `unit`。均为去除首尾空白后非空的字符串，最多分别为 80、40 个字符。同一轴所有数值须使用声明的单位，程序不能检测单位混用。
- `points`：含 1 至 100 个普通字典的普通列表。每点必须包含 `x`、`y`，可选 `label`，不得有其他字段。提供的标签去除首尾空白后非空且不超过 80 个字符；省略时按输入顺序使用 `Point N`。
- 坐标：精确 Python `int` 或 `float` 类型，转换为有限 binary64。拒绝布尔值、数值字符串、子类、NaN、无穷大及转换溢出的整数。超出 binary64 精确整数范围的有限整数可能丢失精度；元数据保留转换值，而非原始任意精度整数。
- 文本仅允许 XML 1.0 字符。结构、类型、数量、文本或数值无效时抛出 `ValueError`，不返回部分资产。这是进程内 Python 契约，不是 HTTP 端点或 JSON 解析器。

## 显示和输出

SVG 画布固定为 720×500，每轴有五个等距刻度。坐标边界来自序列最小值和最大值。x 值由左向右递增，y 值由下向上递增；常量轴的点位于中点。刻度文本保留五位有效数字，绘图坐标保留六位小数，此显示精度不增加分析精度。非常接近的值可能具有相同刻度标签或像素位置。刻度标签仍为经过舍入的显示值，不能用于恢复精确源值。

已处理三项显示问题：y 轴标签与圆点采用一致的低值到高值映射；端点标签保留输入边界；中间刻度不再因浮点抵消丢失小残差。对于五个固定刻度比例（0、1/4、1/2、3/4、1），辅助函数使用标准库有理数运算，从已转换为 binary64 的边界精确计算加权值，再仅转换一次为 binary64 以供显示。例如，边界为 `-1e20` 和 `math.nextafter(1e20, math.inf)` 时，中点现在保留为 `8192` 而非 `0`；镜像情况保留为 `-8192`。此有界计算仅用于刻度标签，圆点坐标、源值、校验及统计行为均不变。刻度运算涵盖有限边界的跨度溢出和次正规数；显示转换及五位有效数字格式仍会舍入。

使用标准库 XML 文本节点转义，SVG 标签和属性固定，不含脚本或外部资源。不调用文件系统、网络、数据库或进程。已有 [asset 封装器](../app/services/saved_report.py) 提供 Base64 内容、SHA-256、字节数及 8 MiB 上限。有界文本及最多 100 个点使接受的输入低于此上限。不修改全局 XML 命名空间注册。

## 示例

```python
from app.services.synthetic_point_plot import render_synthetic_result_scatter

plot = render_synthetic_result_scatter({
    "data_origin": "synthetic",
    "title": "合成可靠度点",
    "estimand": "可靠度 R(t)",
    "x_axis": {"label": "时间", "unit": "小时"},
    "y_axis": {"label": "可靠度", "unit": "概率"},
    "points": [
        {"x": 0.0, "y": 1.0, "label": "起点"},
        {"x": 100.0, "y": 0.99, "label": "点 1"},
    ],
})
print(plot["mime_type"], plot["sha256"], plot["point_count"])
```
