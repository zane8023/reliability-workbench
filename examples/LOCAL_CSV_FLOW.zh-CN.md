# 进程内 CSV → 指数点估计 → 报告候选

此候选为实验性进程内源码预览；不是网页、网络服务、文件上传器、数据库或完整工作台。`analyze_csv(raw, time_unit, locale)` 接收 CSV **字节**、单一时间单位和 `en`/`zh-CN` 语言，在调用进程内使用本地候选解析器及已公开的指数拟合和报告渲染器。它不接收文件路径、不提供网络监听、身份认证或持久化；不应暴露为多用户服务。

下面仅为虚构数据。本集成候选使用已核验的公开基线 `c2a0101ec3961f863e0189afd4aaecb1bc5d775e`，保留其后续输入校验和报告修复。在隔离环境中，从本候选的源码目录运行：

```python
from local_csv_exponential_flow import analyze_csv
raw = b"kind,time\nexact,1\nexact,2\nexact,3\nright_censored,4\nright_censored,5\n"
answer = analyze_csv(raw, "hour", "zh-CN")
assert answer["ok"] and answer["result"]["total_exposure"] == 15.0
assert answer["result"]["scale"] == 5.0
```

## CSV 输入合同

- 输入必须为 `bytes`，总长度为 1 至 65,536 字节，包含可选的 UTF-8 BOM。按 UTF-8 解码，允许开头带 BOM；拒绝 NUL 字符和非法 UTF-8。支持 LF、CRLF 换行及 CSV 引号字段。
- 解析后的表头必须依次为 `kind,time`，不能有重复或多余列。每条数据记录必须恰好有两个字段。拒绝空白数据行；允许末尾正常换行。
- 数据记录为 1 至 5,000 条，每个解析后数据单元格最多 64 个字符。事件类型必须严格为 `exact` 或 `right_censored`。
- 时间使用 ASCII 十进制格式，可带正负号、小数点及 `e`/`E` 指数，例如 `1`、`1.5`、`.5`、`1.` 和 `2e0`。拒绝空白、下划线、NaN 和无穷值。十进制值必须大于零且不超过 `2**53`（9,007,199,254,740,992），转换后也必须为有限正浮点数。转换可能舍入；极小的有效输入仍可能因失效率无法表示而在估计阶段失败。
- 所有观测使用一个明确单位：`second`、`minute`、`hour`、`day` 或 `year`。适配器不推断或换算混合单位。语言只能是 `en` 或 `zh-CN`。

格式错误返回解析代码及可用的物理行号，不回显原始单元格；没有精确失效时，流程返回 `NO_OBSERVED_FAILURES`，不调用拟合器。数值或报告无法生成时返回 `FIT_OR_REPORT_FAILED`，一般意外错误返回 `INTERNAL_ERROR`；`MemoryError` 会向调用方传播，不会被记为计算成功。

时间文本可能在转换为二进制浮点时舍入；成功响应会提示，但提示不能阻止精度损失。成功响应同时包含**规范化后的逐条观测**、计算结果和 Base64 HTML 摘要，可能包含敏感数据；调用者应保护进程内存与结果，不要无意记录或传输。报告只展示选定字段，不是完整可复现归档。指数分布与独立非信息删失是假设，需由使用者验证；少量失效的警告应保留。不包含置信区间、Weibull 拟合、市场预测或图表。

本地测试屏蔽部分常见文件打开和 socket 连接并检查计算次数，这不能证明所有依赖或调用方均无 I/O；系统仍可能交换内存或记录数据。候选使用通用 `app` 名称，仅在隔离副本中核验过模块来源，其他进程中可能与同名包冲突。真实文件路径、链接、Excel、存储、鉴权、多用户、视觉、完整端到端和 VDI 尚未验收；源码公开不代表部署或完整工作台已通过验收。
