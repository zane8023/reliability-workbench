# Nelson–Aalen 累积风险点估计：实验性源码预览

这是实验性进程内源码预览，不是完整可靠性工作台，也不是原非参数服务的完整导出。它复用已公开的 Kaplan–Meier 模块产生的事件时间与风险集，该模块字节与 e353434 版本保持一致，逐时刻累加 `d/n`；**不把 Kaplan–Meier 生存率转换为累积风险**。同时间的失效数分组为 `d/n`，同时间删失者先计入风险集；不同并列事件约定可能有差异。

2026-11-06 的集成以公开基线 `87513889038fb31a446e311586cc6cf33abe5218` 为审查对象，保留其后续 CSV、输入校验及报告变更。在隔离源码副本中运行以下虚构示例：

```python
from fractions import Fraction
from app.services.nelson_aalen import nelson_aalen_point
answer = nelson_aalen_point([1, 2], [2, 3], time_unit="hour")
assert abs(answer["rows"][-1]["cumulative_hazard"] - float(Fraction(7, 12))) < 1e-15
```

此候选要求失效/右删失分别为列表或元组、最多 10,000 个观测、明确单位（second/minute/hour/day/year）、正的有限时间和至少一个失效。**零时刻与全删失在本候选中被拒绝是预览质量门，不代表它们在统计学上必然无效。**不自动换算单位；不可精确表示的整数、布尔和非有限值被拒绝，已按二进制浮点舍入的输入无法还原。结果只提供事件时刻的累积风险点估计、风险集、计数和限制；不提供生存率转换、置信区间、延迟进入、外推、图表或真实使用条件下的可靠性预测。

每个观测应对应一个单位，并假设右删失独立、无信息；这些假设、数据来源、事件定义和工程适用性均未由计算器验证。数据不足时不得把点估计当成保证。现有报告渲染器未适配此类型，不能将其伪装为其他模型报告。

来源：项目授权范围内的公开 Kaplan–Meier 风险集及标准 `d/n` 方法；方法参考 [Brian P Hobbs（2015）](https://pmc.ncbi.nlm.nih.gov/articles/PMC4617278/)。原工程中另有更广的非参数实现及相关来源/许可待查，本候选没有引入 `reliability` 库或复制整个原服务；其余第三方依赖仍按各自许可。本地比较不证明历史来源或全球范围无复制。
