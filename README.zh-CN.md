# Reliability Workbench
## 可靠性分析与风险决策工作台

[English](README.md) | [安装与验证](INSTALL.zh-CN.md)

这是可靠性工程早期源码预览，当前开放 **Arrhenius 正向加速因子及可选寿命换算**，以及 **给定参数的 Weibull 和指数分布可靠性指标**（可靠度、失效概率、风险率和分位寿命）。参数由使用者提供，示例使用虚构数值；其他加速模型及全部参数反求在公开入口明确禁止；不包含分布拟合、校准或市场预测。

在 Windows x64、Python 3.10.11 的独立环境中，两个合成示例和 25 项聚焦测试已使用官方 PyPI 固定哈希 wheel 通过。其他环境和更广泛模型尚未验证。本预览从项目目录运行模块，未提供或测试 `pip install` 项目本身；详见[安装与验证](INSTALL.zh-CN.md)。

合成检查不能验证失效机制、参数、产品寿命或市场预测，也不能单独作为决策依据。行业知识、报告、市场风险工作流及 AI 接入属于未来目标，不在当前预览中。
