# Reliability Workbench
## 可靠性分析与风险决策工作台

[English](README.md)

面向可靠性分析与市场端失效风险评估的工程工作台，目标是串联数据整理、试验条件核对、寿命建模与可复核报告，支持可配置的行业知识与模型参数。

## 本仓库当前提供什么

目前发布的是项目说明，**尚无可安装的公开源码发行版或安装包**。小范围的加速寿命计算候选已在全新 Windows / Python 3.10.11 x64 虚拟环境中通过合成示例和 6 项聚焦测试，固定版本 PyPI wheel 哈希及依赖一致性已核对。源码来源与许可证审查仍未完成；这不代表完整工作台、全部模型或市场端预测已验证。

首个公开计算版本将以一个可复核的合成案例为目标，明确输入、单位、假设、参考结果和适用限制。完整分析流程、图文报告、AI 接入和市场风险预测尚未在本仓库发布或完成公开版本验收。

## 使用与验证原则

- 数值计算使用可审查的方法，AI 输入整理和解释不替代计算验证。
- 加速外推需要合适的失效机制、模型、试验条件和数据证据。
- 缺少必要条件时明确说明缺项，不补造真实参数。
- 示例参数仅用于演示，不是任何实际产品的推荐参数。
- 工程分析不构成产品寿命保证；市场端预测需要相应验证。
