# Reliability Workbench
## 可靠性分析与风险决策工作台

[English](README.md) | [安装与验证](INSTALL.zh-CN.md) | [示例说明](examples/README.zh-CN.md)

这是可靠性工程早期源码预览，当前开放 **Arrhenius 正向加速因子及可选寿命换算**，**给定参数的 Weibull 和指数分布可靠性指标**（可靠度、失效概率、风险率和分位寿命），以及基于完整失效与右删失数据的**指数分布点估计**。本地 HTML 报告可展示已保存结果的选定字段，不重新计算，暂不包含图表。参数由使用者提供，示例使用虚构数值；其他加速模型及通用参数反求入口明确禁止；不包含 Weibull 拟合、寿命参数置信区间、校准或市场预测。

在 Windows x64、Python 3.10.11 的独立环境中，三个数值示例和 46 项聚焦测试已使用官方 PyPI 固定哈希 wheel 通过。其他环境和更广泛模型尚未验证。本预览从项目目录运行模块，未提供或测试 `pip install` 项目本身；详见[安装与验证](INSTALL.zh-CN.md)。

指数点估计假设寿命相互独立且同服从指数分布，并假设右删失独立、无信息性；计算本身不能验证这些假设，失效事件很少时估计可能不精确。合成检查不能验证失效机制、参数、产品寿命或市场预测，也不能单独作为决策依据。行业知识、综合图文报告、市场风险工作流及 AI 接入属于未来目标，不在当前预览中。

本预览还提供[ Kaplan–Meier 生存点估计](examples/KAPLAN_MEIER.zh-CN.md)，支持完整失效和右删失，假设独立非信息性删失，不提供置信区间或外推。在 Windows x64 / Python 3.10.11 隔离环境中，使用固定哈希 wheel 的 60 项测试和合成示例已通过。

可选的[行业配置格式校验器](examples/DOMAIN_CONFIG.zh-CN.md)检查示意性元数据，不接入计算；格式通过不代表来源真实或工程适用。

**实验性[零失效单侧二项上限](examples/ZERO_FAILURE.zh-CN.md)** 已提供，结果是试验窗口概率的单侧置信上限，不是时间失效率或市场预测；65 项测试在文档所述 Windows/Python 3.10.11 环境验证。

## 本地 CSV 内存分析候选

此实验性进程内源码预览在已核验的公开基线 c2a0101 上，将合成 CSV 字节接入既有指数点估计和字段白名单 HTML 报告，保留后续输入校验及报告修复，原有两个适配器保持不变。它不提供文件、存储、网络或网页服务。原候选已有 Windows/Python 3.10.11 验证记录，但不能据此认定本次集成修订已通过 Windows 验证；本次集成通过 67 项 Linux 定向检查，但未重新进行完整测试套件、Windows 或视觉验收。它不是完整工作台、可 pip 安装的项目或已验证的市场预测。详见[中文示例与 CSV 合同](examples/LOCAL_CSV_FLOW.zh-CN.md)和[英文示例](examples/LOCAL_CSV_FLOW.md)。

## 实验性 Nelson–Aalen 点估计

2026-11-06 在已审查的公开基线 8751388 上新增的实验性源码预览提供 [Nelson–Aalen 累积风险点估计](examples/NELSON_AALEN.zh-CN.md)，复用已公开的事件和风险集行，按分组 `d/n` 累加；它不是由 Kaplan–Meier 生存率转换得到，也不提供置信区间。正时间及至少一次精确失效是预览质量门，不是普遍的统计规则。输入及独立无信息删失假设尚未验证，不提供真实使用条件下的可靠性预测。本次集成通过 22 项 Linux 定向检查、双语示例和另外 3,000 组合成参考案例；这不是新的完整套件、Windows、视觉或 VDI 验收。
